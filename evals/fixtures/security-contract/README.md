# Native security contract fixture

The source starts clean. Case overrides add two explicit eval calls or a synthetic PEM-shaped string. The PEM payload is not a usable private key. The local Opengrep rule determines the expected rule/location, independently of any public rule feed. Dependency cases override the minimal lock with a nonexistent test package; no dependency is installed. The local advisory provider supplies fixed native records and severity. This fixture evaluates OxGuard normalization and reporting, not production security accuracy.
